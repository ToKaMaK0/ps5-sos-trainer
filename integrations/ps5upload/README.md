# Stock PS5Upload 7.5.2

The current 30-entry JSON is live-tested with stock PS5Upload 7.5.2. No custom helper is required. One preparation option owns the resource code and quantity hook; each of the 26 resources owns only its flag. Enable preparation first and disable it last. Combat and jump are independent.

All JSON defaults are off. Reader presets/autoload choices are separate and may persist; clear old choices when changing layouts. Updating a PC app does not by itself replace its console helper.

The older `session-cheats.patch` is retained as a GPL-3.0-or-later historical integration artifact, not a current installation requirement. Do not install the old 7.1.11 helper over a current release. Source contracts: https://github.com/phantomptr/ps5upload/tree/v7.5.2
